# PHASE 11: ブラウザ版レスポンシブ対応

## 目的

現在の3カラムレイアウト（左サイドバー + メイン + 右サイドバー）はデスクトップ専用で設計されており、
モバイル・タブレット幅では表示が崩れる。スマートフォン〜タブレット〜デスクトップまで適切に表示できるよう対応する。

---

## 現状の問題点

| 箇所                                     | 問題                                 |
| ---------------------------------------- | ------------------------------------ |
| 左サイドバー `w-72` (288px)              | 常時表示のため狭い画面でメインを圧迫 |
| 右サイドバー `w-80` (320px)              | 同上。ひらがな/翻訳カードが縦に並ぶ  |
| 文字起こしカードのpadding `p-12`/`px-12` | モバイルで余白が大きすぎる           |
| カード下部コントロール `px-12 pb-10`     | 同上                                 |
| ヘッダー `px-8`                          | モバイルで左右余白が大きすぎる       |
| ソースエリアのpillタブ                   | 小さい画面でボタンが押しにくい       |

---

## ブレークポイント戦略

Tailwind CSS の標準ブレークポイントを使用。

| ブレークポイント       | 幅              | レイアウト                                                                |
| ---------------------- | --------------- | ------------------------------------------------------------------------- |
| デフォルト（モバイル） | `< 768px`       | 1カラム。左サイドバー非表示。右サイドバーをメイン下に縦積み               |
| `md`                   | `768px〜1024px` | 2カラム。左サイドバー非表示。右サイドバーはメイン右に表示（`w-64`に縮小） |
| `lg`                   | `≥ 1024px`      | 3カラム。現在のレイアウトを維持                                           |

---

## 具体的な変更内容

### 1. 左サイドバー（履歴エリア）

現状: `w-72 flex flex-col` で常時表示

```html
<!-- 変更後 -->
<aside
  id="left-sidebar"
  class="hidden lg:flex lg:w-72 flex-col bg-transparent shrink-0"
></aside>
```

- `lg` 未満では `hidden`（非表示）
- `lg` 以上でのみ表示

### 2. 右サイドバー（ひらがな/翻訳/要約カード）

現状: `w-80 flex flex-col p-6` で常時表示（横並び）

```html
<!-- 変更後 -->
<aside
  id="right-sidebar"
  class="flex flex-col md:w-64 lg:w-80 p-4 md:p-6 gap-4 overflow-hidden shrink-0
         w-full md:flex-col"
></aside>
```

- モバイル: メインセクションの **下** に配置（`flex-col` をメインレイアウトに追加）
- `md` 以上: サイドバーとして右に表示（`w-64`）
- `lg` 以上: 現在の `w-80` を維持

### 3. メインレイアウト（`<main>`）

現状: `flex overflow-hidden`（横並び固定）

```html
<!-- 変更後 -->
<main class="flex-1 flex flex-col md:flex-row overflow-hidden min-h-0"></main>
```

- モバイル: `flex-col`（縦積み。メイン→右サイドバーの順）
- `md` 以上: `flex-row`（横並び）

### 4. 文字起こしカード padding

現状: `p-12`（48px）/ `px-12 pb-10`

```html
<!-- 変更後 -->
<div class="p-5 md:p-8 lg:p-12 flex-1 min-h-0">
  <div
    id="card-controls"
    class="px-5 pb-6 md:px-8 md:pb-8 lg:px-12 lg:pb-10 shrink-0"
  ></div>
</div>
```

### 5. ヘッダー padding

現状: `px-8`

```html
<!-- 変更後 -->
<header
  class="h-14 flex items-center justify-between px-4 md:px-8 ..."
></header>
```

### 6. ソースエリア（pillタブ）

現状: ボタンが `px-6 py-2` で固定幅

```html
<!-- 変更後 -->
<button class="source-btn active px-4 md:px-6 py-2 ...">マイク</button>
```

### 7. モバイル時の右サイドバーカード高さ制限

右サイドバーをメイン下に表示する際、カードが画面を占有しすぎないよう高さを制限する。

```html
<!-- 右サイドバーの各カード -->
<div
  class="flex-1 flex flex-col ... min-h-0 md:flex-1 max-h-48 md:max-h-none"
></div>
```

## 変更ファイル

| ファイル                   | 変更内容                                                             |
| -------------------------- | -------------------------------------------------------------------- |
| `app/static/index.html`    | ブレークポイント対応クラスの付け替え（上記7点）                      |
| `app/static/css/style.css` | 不要（Tailwindで完結。既存のメディアクエリは旧UIのもので影響しない） |

---

## 変更しないもの

- JS（`app.js`, `ui-controller.js` 等）: レイアウト変更のみのためロジック変更なし
- Zenモード: 既にサイドバーを非表示にするため、モバイルでも自然に動作する
- ダークモード: Tailwindクラスで対応済みのため変更不要

## テスト項目

| ケース                       | 確認内容                                                  |
| ---------------------------- | --------------------------------------------------------- |
| 幅 375px（iPhone SE）        | 1カラム表示。左サイドバー非表示。右カードがメイン下に表示 |
| 幅 768px（iPad縦）           | 左サイドバー非表示。右サイドバーが右に表示（w-64）        |
| 幅 1024px（iPad横）          | 3カラム表示（左サイドバー表示）                           |
| 幅 1280px（デスクトップ）    | 現在のレイアウトと同一                                    |
| Zenモード（モバイル）        | サイドバーが非表示になり文字起こしのみ全画面表示          |
| ダークモード × モバイル      | 色が正しく適用されている                                  |
| 録音中のソースエリアフェード | モバイルでも正常にフェードアウトする                      |
